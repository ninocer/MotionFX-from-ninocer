# MotionFX — Android editor foundation

Реальный исходный Android-проект на Kotlin + Jetpack Compose, Android 13+.
Текущая версия **0.1, ранняя проверяемая база**, не полный аналог After Effects.
Статус сборки определяется GitHub Actions, а не наличием исходников.

## Скачать APK без Android Studio на Windows

1. Откройте вкладку **Actions** этого репозитория → **Android APK**.
2. Выберите запуск для нужной ветки/коммита. Дождитесь успешных `build` и
   `device-tests`; изучите логи, если проверка красная.
3. Внизу запуска откройте **Artifacts → MotionFX-debug-N** и скачайте ZIP
   (нужна авторизация GitHub). Распакуйте `app-debug.apk` и перенесите на телефон.
4. Разрешите установку из выбранного файлового менеджера и установите APK.

Ничего из JDK, SDK, Android Studio или Gradle устанавливать на Windows не нужно.
Все Android-сборки и тесты запускаются на Linux runner в GitHub. В репозиторий
включены файлы Gradle Wrapper; они сами по себе не устанавливают инструменты.

Workflow `.github/workflows/android.yml` запускается при push, pull request и
вручную через Run workflow. Он устанавливает Temurin JDK 17, SDK 35, использует
Gradle 8.11.1 с проверкой SHA-256, запускает unit-тесты и Android Lint, собирает
Debug APK и сохраняет отчёты/логи даже при ошибке. Отдельная задача запускает
инструментальные тесты на эмуляторе API 35. APK публикуется только после успешной
задачи build; зелёный статус всего запуска дополнительно требует device-tests.
Срок хранения артефакта — 30 дней; повторный push создаёт новую сборку.

## Сквозной сценарий

1. **Проекты → Новый проект**: имя, размеры, длительность, FPS; пресеты 16:9,
   9:16, 1:1, 4:3 и собственные чётные размеры.
2. **+ Медиа**: импорт видео/изображений через системный выбор документов.
   Можно наложить несколько файлов, текст и фигуры.
3. Выберите слой в таймлайне → **Свойства**. Меняйте X/Y, масштаб, поворот,
   непрозрачность. Кнопка ◆ добавляет ключ; при наличии ключей ползунок создаёт
   или меняет ключ в текущей позиции курсора. Выберите другую позицию и значение.
4. Play показывает анимацию. Доступны Linear, Hold, Ease In/Out/In-Out и
   фиксированная Cubic Bezier. Предпросмотр до 480 px по длинной стороне.
5. **Эффекты**: Brightness, Contrast, Saturation и Tint реально меняют кадры;
   их параметры можно анимировать.
6. **Экспорт**: настоящий MP4 H.264/H.265 через MediaCodec → EGL → MediaMuxer,
   либо PNG текущего кадра. Файлы сохраняются в Movies/MotionFX или
   Pictures/MotionFX. Есть прогресс, отмена и сообщения об ошибках.

**MP4 в версии 0.1 без звука**, включая исходный звук импортированного видео.
Это указано в интерфейсе. Во время экспорта оставляйте приложение открытым.
Разрешение задаётся короткой стороной (720/1080/1440/2160); максимальная длинная
сторона — 3840. Encoder проверяет формат, FPS и битрейт на устройстве; неподдерживаемые
режимы отклоняются. Наличие пункта 4K/60 не означает гарантированную поддержку.

Слои: порядок, видимость, блокировка, дублирование, удаление, split, trim;
undo/redo до 50 снимков. Проекты: создание, открытие, копирование, удаление,
автосохранение, ручное сохранение, экспорт/импорт `.mfx` и восстановление атомарной
записи. Перенесённые `.mfx` не содержат медиафайлы: URI привязаны к устройству.

## Плагины

Через **Плагины** установите `examples/violet-film.mfxplugin`, выберите слой и
нажмите **Применить**. Это рабочий пресет из Tint/Contrast/Saturation. Поддержаны
установка, удаление, включение/отключение и проверки версии. Формат декларативный,
произвольный код не исполняется. [Plugin API](docs/PLUGIN_API.md).

## Границы текущей версии

Ещё не реализованы: аудиомикшер/экспорт звука, GPU-композитор всех слоёв,
низколатентное аппаратное декодирование, интерактивный Graph Editor,
редактирование Bezier-контролей, маски/mattes, parenting, группы, precomposition,
adjustment/null, blend modes, motion blur, 3D, большинство профессиональных
эффектов, переходы и пользовательские GLSL-плагины, PNG sequence, прокси,
перетаскивание слоёв по времени, thermal adaptation и полноценное профилирование.
Масштабирование таймлайна доступно жестом и ползунком; порядок слоёв — кнопками.

Общий FrameRenderer рисует CPU Canvas, а видео получает через
MediaMetadataRetriever. Это точный по времени reference pipeline, а не
оптимизированный real-time engine. Одновременно удерживается максимум два
retriever и три уменьшенных изображения. Предпросмотр не перерисовывается без
изменений; экспорт выполняется в фоне корутин. 30/60 FPS предпросмотра,
120 FPS UI, скорость 4K-экспорта и отсутствие перегрева пока **не подтверждены**.

Приложение без рекламы, аккаунтов, сети, водяного знака и подписок. Русский и
английский UI переключаются кнопкой RU/EN; технические ошибки могут быть на
английском. Нет FFmpeg/NDK и стороннего исполняемого кода.

## Архитектура и проверки

- `core`: неизменяемая модель, интерполяция, операции слоёв, история, JSON.
- `storage`: AtomicFile и локальные проекты.
- `render`: общий compositor, EGL surface, MediaCodec exporter, MediaStore.
- `plugins`: ограниченный версионированный API, ZIP validator, manager.
- `MainActivity`: Compose editor, импорт, управление проектами и экспортом.
- Unit tests: таймлайн/split, ключи/easing/Bezier, сериализация, history, plugins.
- Device tests: изменение пикселей эффектами, сохранение проектов, настоящий
  MP4, число/временные метки кадров и декодирование результата.

Документ: [формат .mfx](docs/PROJECT_FORMAT.md).
Версии сборки закреплены: AGP 8.9.2, Kotlin 2.1.20, JDK 17, Gradle 8.11.1.
При наличии отдельной облачной Linux-среды с SDK команды:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --stacktrace
./gradlew :app:connectedDebugAndroidTest --stacktrace
```

Путь после успешной сборки на runner: `app/build/outputs/apk/debug/app-debug.apk`.
Debug подписывается стандартным debug-ключом runner; между запусками он может
меняться, поэтому обновление поверх старого APK может потребовать удаления
приложения (сначала сохраните проекты). Постоянный release-ключ не создаётся и
не хранится в репозитории; подписанного production Release сейчас нет.
